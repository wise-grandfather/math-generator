# math-generator

Генератор математических примеров для печати с ответами на обороте листа.

## Возможности

- **Дроби** — сложение, вычитание, умножение, деление
- **Степени и корни** — квадратные, кубические, произвольной степени
- **Линейные уравнения** — различные формы записи
- **Настройка через `config.json`** — количество примеров, знаки операций
- **Автоподбор шрифта** под размер ячейки
- **Ответы на обороте** — зеркальные колонки для двусторонней печати

## Быстрый старт

1. Скачай `math_gen.exe` и `config.json` из [Releases](https://github.com/ТВОЙ_НИК/math-generator/releases)
2. Положи оба файла в одну папку
3. Запусти `math_gen.exe`
4. Жми Enter для стандартных настроек или введи свои
5. Получи `math_worksheet.docx` — печатай!
